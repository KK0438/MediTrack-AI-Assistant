# 💊 MediTracker – Smart Medicine Reminder System

MediTracker is a **web-based medication management platform** that helps users track their medicines, receive reminders,
and monitor medication adherence. The system combines **reminder automation, health insights, and AI-powered assistance** 
to help users maintain consistent medication routines.


# 🚀 Features

## 1. Medicine Schedule Management

* Add medicine details such as **pill name, dosage, time, and frequency**
* Edit or delete medication schedules
* Maintain a clean medication database

## 2. Smart Reminder System

Users receive reminders through multiple channels:

* 📧 **Email reminders** (via Nodemailer)
* 🔔 **Browser notification popups**
* ⏰ **Scheduled reminders before medication time**

This ensures users never miss important doses.

---

## 3. Dose Tracking System

The application tracks medication adherence:

* Mark doses as **taken or missed**
* Maintain a **history of medication activity**
* Helps users monitor their consistency

---

## 4. Interactive Dashboard

A user-friendly dashboard provides:

* Upcoming medication reminders
* Past medication logs
* Overview of medication schedules

---

## 5. Data Visualization

The platform provides analytics including:

* 📊 Medication adherence rate
* 📉 Missed doses tracking
* 📈 Trends over time

These insights help users understand their medication habits.

---

## 6. Health Information Blog

The application integrates a **health-related API** that displays:

* Health articles
* Wellness tips
* Informational medical content

This allows users to stay informed about health topics.

---

## 7. AI Health Assistant (Optional Feature)

Users can interact with a chatbot to ask questions such as:

* “What medicines do I need to take today?”
* “Did I miss any doses yesterday?”

---

## 8. Contact & Communication System

Users can reach out through a **contact form**.

* Emails are sent using **SendGrid**
* Ensures reliable message delivery.

---

# 🛠 Tech Stack

### Frontend

* React.js
* React Libraries
* CSS / UI Components

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### Email Services

* Nodemailer (Reminder Emails)
* SendGrid (Contact Form Emails)

### APIs

* Health Information API (for blog content)


# 🏗 System Architecture

Frontend (React)
        ↓
Backend API (Node.js + Express)
        ↓
Database (MongoDB)
        ↓
Email Services (Nodemailer / SendGrid)
        ↓
Notification System (Browser Alerts)
